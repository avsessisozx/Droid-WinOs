## Ne işe yarar
Telefondaki bir `.exe` dosyasını seçersin, Droid-WinOs onu Linux ortamında Windows uyumluluk katmanıyla (Proton) çalıştırır.

## Kurulum
1. [Releases](../../releases) sayfasından `app-release.apk` dosyasını indir ve kur.
2. Uygulamayı aç. İlk seferde alttaki düğmeyle Linux çalışma ortamını kur (bir kez, internet gerekir).
3. **Program ekle (.exe)** düğmesiyle bir program seç.
4. Listedeki programa dokun, çalışsın. Listeden silmek için uzun bas.
